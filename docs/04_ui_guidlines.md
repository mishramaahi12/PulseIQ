# PulseIQ UI Guidelines

## Design Philosophy

PulseIQ should look like a professional SaaS product used by real businesses.

The interface should feel clean, trustworthy, modern, and minimal.

Avoid flashy or AI-generated design patterns.

---

# Theme

Default Theme:
Light Mode

Future:
Dark Mode (Optional)

---

# Colors

Background:
#F8FAFC

Cards:
White

Primary:
#2563EB

Success:
Green

Warning:
Orange

Danger:
Red

---

# Typography

Font:
Inter

Style:
Simple, readable, professional.

---

# Border Radius

Medium rounded corners.

Avoid overly rounded components.

---

# Shadows

Use soft shadows only.

No glowing effects.

---

# Buttons

Primary Button:
Solid Blue

Secondary Button:
White with blue border

Buttons should have clear labels like:

- Get Started
- Explore Demo
- Upload Sales Data
- Ask PRISM
- Export Report

Avoid generic labels like:
- Submit
- Click Here

---

# Sidebar

Simple vertical navigation.

Items:

- Dashboard
- Sales
- Inventory
- Customers
- Expenses
- Reports
- PRISM
- Settings

---

# Dashboard

Top Cards:

- Revenue
- Profit
- Expenses
- Orders
- Customers
- Business Health Score

Below Cards:

- Sales Trend
- Product Performance
- Inventory Status
- Customer Insights

---

# Charts

Professional business charts only.

Avoid unnecessary colors.

Keep charts clean and readable.

---

# Icons

Use simple outline icons.

Avoid cartoon or 3D icons.

---

# Animations

Only subtle animations.

Allowed:

- Fade
- Hover
- Loading

Avoid:

- Floating effects
- Neon glow
- Excessive motion

---

# 3D Usage

Allowed only for:

- Landing Page Hero
- Demo Illustration
- Empty State

Dashboard should remain clean and professional.

---

# Overall Goal

When someone opens PulseIQ, it should feel like a real enterprise business platform, not an AI-generated student project.
