# PulseIQ

AI-powered Business Intelligence Dashboard

## Features

- Login & Signup
- Dashboard Analytics
- Revenue Charts
- Customer Management
- Reports
- Settings
- Prism AI Assistant

## Tech Stack

Frontend:
- React
- Vite
- Tailwind CSS
- Recharts

Backend:
- FastAPI
- SQLAlchemy
- MySQL

Run Frontend

```bash
npm install
npm run dev
```

Run Backend

```bash
python -m uvicorn main:app --reload
```
