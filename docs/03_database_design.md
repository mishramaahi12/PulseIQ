# PulseIQ Database Design

## Overview

PulseIQ uses a relational database to store business information, transactions, customers, inventory, expenses, reports, and AI insights.

---

# Main Tables

## Users

Stores user account information.

Fields:

- User ID
- Full Name
- Email
- Password
- Phone Number
- Created At

---

## Businesses

Stores business details.

Fields:

- Business ID
- User ID
- Business Name
- Business Type
- Currency
- Financial Year
- Created At

---

## Products

Stores product details.

Fields:

- Product ID
- Business ID
- Product Name
- Category
- Cost Price
- Selling Price
- Current Stock

---

## Sales

Stores every sale.

Fields:

- Sale ID
- Product ID
- Quantity Sold
- Total Amount
- Profit
- Date

---

## Customers

Stores customer information.

Fields:

- Customer ID
- Business ID
- Customer Name
- Phone Number
- Total Purchases
- Last Purchase Date

---

## Inventory

Stores inventory status.

Fields:

- Inventory ID
- Product ID
- Available Stock
- Low Stock Alert
- Last Updated

---

## Expenses

Stores business expenses.

Fields:

- Expense ID
- Business ID
- Category
- Amount
- Date

---

## AI Insights

Stores insights generated by PRISM.

Fields:

- Insight ID
- Business ID
- Insight
- Recommendation
- Generated At
